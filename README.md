# SD 提示詞生成器 (SD Prompt Generator) - v3.9.5

這是一個專為 Stable Diffusion 創作者設計的提示詞（Prompt）輔助工具，提供直觀的分類介面與分區優化，讓使用者能快速組合出高品質的生成指令。

## 🚀 主要特色

- **分區優化管理**：將提示詞細分為人物、環境、動作、畫質等 10 大類，並包含數百個中英對照標籤。
- **視覺化標籤排序**：
    - 點擊標籤即可即時新增。
    - **支援拖曳排序**：在「已選標籤」區按住 `Ctrl` 鍵即可自由調整標籤順序，輕鬆控制 SD 生成時的權重邏輯。
- **一鍵高品質起手式**：內建「魔術棒」按鈕，快速填入 `masterpiece`, `8k`, `ultra-detailed` 等核心增益詞。
- **負面提示詞庫**：預設強大的負面詞（Negative Prompt）模板，並提供清空與一鍵複製功能。
- **完全響應式設計**：採用深色系 UI 與過濾捲軸處理，支援不同螢幕尺寸。

## 🛠️ 技術棧

- **Frontend**: HTML5, Tailwind CSS
- **Icons**: Lucide Icons
- **Logic**: Vanilla JavaScript

## 📂 檔案結構

- `SDPrompt.html`: 核心網頁檔案，包含 UI 結構與互動邏輯。
- `tabsData.js`: 提示詞數據庫，儲存所有標籤的分類、英文 Value 與中文 Label。

## 💡 使用提示

1. **基本操作**：在下方標籤區點擊感興趣的內容，標籤會自動出現在上方輸入框中。
2. **調整順序**：在「已選標籤」區，按住鍵盤 **Ctrl** 鍵不放，即可用滑鼠拖曳標籤方塊來調整先後順序。
3. **複製匯出**：點擊輸入框旁的「複製」圖示，即可直接貼上到 WebUI、ComfyUI 或 Forge 等生成工具中。
4. **手動權重**：工具提供提示，若需加強特定詞彙，可自行在輸入框加強括號（如 `(tag:1.3)`）。
